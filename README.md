# Ledger — установка как приложение

Папка готова к размещению на любом статическом хостинге (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
Всё, что нужно — отдать эти файлы по HTTPS из одной директории.

## Состав

- `index.html` — само приложение, один самодостаточный файл
- `manifest.webmanifest` — описание приложения: имя, иконки, цвет, режим отображения
- `sw.js` — service worker: кэширует оболочку, чтобы приложение открывалось без интернета
- `icon-192.png`, `icon-512.png` — иконки для Android и рабочего стола
- `icon-maskable-512.png` — иконка под адаптивные формы Android (круг, squircle)
- `apple-touch-icon.png` — иконка для домашнего экрана iOS

## Как разместить за 5 минут (GitHub Pages)

1. Создайте репозиторий на github.com, загрузите в него содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту адрес вида `https://ваш-логин.github.io/ledger/` станет рабочим.

Netlify и Cloudflare Pages принимают папку перетаскиванием, без git.

## Как добавить ярлык

- **Android, Chrome:** откройте адрес → меню (⋮) → «Установить приложение».
- **iOS, Safari:** откройте адрес → «Поделиться» → «На экран "Домой"». Только Safari, в Chrome на iOS этого пункта нет.
- **Windows / macOS, Chrome или Edge:** значок установки в адресной строке, либо меню → «Установить Ledger».

После установки приложение открывается в отдельном окне без адресной строки и работает офлайн.

## Важно про данные

Операции хранятся в localStorage того браузера, где вы их импортировали.
Установленное приложение и обычная вкладка на том же адресе используют одно хранилище,
а вот локальный файл (`file://`) — уже другое. Между устройствами данные не синхронизируются.
